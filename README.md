## 🚀 Featured project: SlideWise

**SlideWise** is a slide-by-slide PowerPoint generator I’m building for hackathons and competitions. Give it a **reference presentation** and a **problem statement**, and it aims to create a polished deck in minutes—with research-backed content and visuals chosen to support the story.

<div align="center">

`REFERENCE PPT` + `PROBLEM STATEMENT` → `RESEARCH` → `SLIDE-WISE STORY` → `VISUALS · GRAPHS · FLOWCHARTS` → `PRESENTATION`

</div>

### What makes SlideWise useful

- 📎 Starts from the user’s reference PowerPoint and problem statement
- 🔎 Builds the presentation around research-backed content
- 📊 Uses visuals, graphs, and flowcharts to make ideas easier to understand
- 🧩 Organizes the result slide by slide, ready to refine and present
- ⚡ Aims to turn a time-consuming deck-building process into a workflow that takes minutes

**Status:** In progress · Hackathon and competition project
